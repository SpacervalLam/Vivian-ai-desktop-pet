# 工作台内嵌浏览器

入口：工作页右侧检查器 →「页面」，或设置 → 外部连接 →「打开内嵌浏览器」。展开按钮可将浏览器扩展到工作区域。此功能需要重新编译 Rust 桌面程序；仅更新前端无法启用原生页面。

## 实现与能力

使用独立 WebView2 环境和原生子控制器，每个标签页拥有自己的导航栈。页面直接加载，支持普通网页交互、脚本、登录存储、原生右键菜单、文件选择、上传、下载和 PDF 查看。工具栏提供：

- 多标签、无痕标签、关闭与重新打开、地址输入和 Bing／Google／百度搜索（在浏览器设置切换）。
- 前进、后退、刷新、停止、缩放、原生页内查找、静音。
- 书签、历史搜索与清理、普通标签恢复。
- 下载列表、暂停、继续、取消及 WebView2 原生下载界面。
- 打印／保存 PDF、另存网页、开发者工具。
- 解压扩展的加载、启停和移除；WebView2 自身的 PDF／剪贴板组件由运行时管理。
- 摄像头、麦克风、位置等网站权限提示；当前配置的网站数据、缓存与权限清理。

`window.open` 通过原生 NewWindowRequested deferral 接到新标签，并设置 NewWindow 保留 opener；脚本关闭弹窗也关闭对应标签。网页全屏元素仍受浏览器视口裁切，工作台侧栏和浮层保持可见。

推荐、最近访问、书签／历史列表及网页标签显示真实站点图标，复用快捷启动页的图标解析器：尝试 favicon、首页声明和常见图标路径，支持应用代理和直连。请求只携带站点 origin，不携带页面路径、查询参数或浏览器 Cookie。前端按站点合并请求并缓存，失败时显示地球图标，短期失败缓存到期后可重试。

`Ctrl+L`／`F6` 定位地址栏，`Ctrl+T` 新标签，`Ctrl+Shift+N` 无痕标签，`Ctrl+W` 关闭，`Ctrl+Shift+T` 恢复，`Ctrl+Tab`／`Ctrl+Shift+Tab` 切换，`Ctrl+F` 查找。原生页面保留其余 WebView2 浏览器快捷键。

浏览器由独立原生子窗口承载，按页面上报的像素比例和容器边界裁切。菜单及悬浮侧栏通过原生窗口区域扣除覆盖范围，无需截图替换、隐藏网页或改变网页尺寸；展开动画开始时按侧栏目标宽度预留遮挡区。

统一页签栏并列网页、文件预览和终端，页签使用固定宽度，超出时横向滚动。新建页面显示初始面板，终端需从面板单独创建。书签、下载、历史和扩展可打开完整内部页面；菜单悬浮显示快捷卡片。完整视图隐藏心智观察器顶部导航。网页滚动条跟随当前深浅主题。

桌宠 `open_url`、网站快捷入口、聊天链接及通知网页入口优先使用内置浏览器，并切到对应页面、恢复和聚焦窗口；内置浏览器不可用时回退系统浏览器。

## 数据与生命周期

用户数据目录 `browser/engine/` 保存引擎资料，`browser/state.json` 保存普通标签、书签、历史。普通标签共享 Default 配置，Private 配置启用 WebView2 InPrivate。无痕页面不进入会话恢复和历史，但下载文件和主动添加的书签保留。清理网站数据作用于当前普通或无痕配置，会清除该配置的登录状态，保留书签、应用历史和已下载文件。

所有 COM 对象只在 Tauri STA 主线程访问，磁盘快照在后台按序原子写入。切换检查器、收起侧栏或卸载页面时隐藏控制器，保留标签。关闭工作窗口时，普通标签移交给私有隐藏窗口，供桌宠继续读取；无痕标签关闭，结束其会话。重新打开时将普通标签接回检查器。布局使用递增序号拒绝过期更新，CSS 坐标按窗口 DPI 转为物理坐标。HTML 菜单、模态层或悬浮侧栏覆盖浏览区时，先在内存中捕获并解码当前视口，再以静态画面承接被隐藏的原生页面；关闭浮层后接回原页面，不重新导航。捕获失败时保留最大可用的原生区域。

网页不注入 Tauri IPC，和应用主 WebView 的环境、Cookie、存储完全独立。采用原生控制器还可保留现有 `memory` WebviewWindow 的窗口管理行为。原生脚本对话框、文件选择、上下文菜单及下载界面交给引擎；没有关闭证书校验或网页安全检查。

## 运行时边界

这是 WebView2 浏览器外壳，功能范围受已安装 Evergreen Runtime 约束。它不提供 Edge 账号同步、Edge／Chrome 扩展商店、完整 Edge 设置中心，也没有扩展工具栏按钮弹窗。扩展兼容性、网站 OAuth 对嵌入式用户代理的限制、DRM／编解码器支持按运行时和网站规则决定。不能承诺与完整 Edge 产品逐项一致。新 API 不可用时显示实际错误，不静默替换为空操作。参考 [WebView2 与 Edge 功能差异](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/browser-features)。

## 桌宠、工作智能体与登录信息

原 Chrome 桥工具已迁移到进程内 WebView2。扩展代码、安装引导、打包资源、回环 WebSocket 服务和协议已移除。`mcp__browser__*` 名称保留以兼容已有权限、禁用设置和会话。平台登录入口会打开内嵌浏览器，不再启动 Chrome。原 Chrome 配置的登录状态不会自动复制，需要在内嵌浏览器登录。

登录后，桌宠可以读取该会话实际加载的页面，使用编号点击、输入、原生按键、滚动、导航和等待；也能在 Default 配置下创建静音后台任务页，沿用普通标签的 Cookie，包括 HttpOnly Cookie。后台页面成功、失败、超时、取消都会回收，不抢占当前标签、不进入浏览历史；需要弹窗、权限或下载时要求改到可见页面处理。后台任务数量会显示在工具栏。

页面操作使用 CDP 隔离上下文中的内置脚本，按会话保留编号和增量状态，不向模型开放任意 JS/CDP 或 Cookie API。读取结果包裹为不可信页面数据，密码等敏感表单值被掩码。快照绑定标签和导航代次，后续动作沿用该标签；用户切换标签不会让动作自动转移，导航后需要新快照。`tab_id` 可显式指定目标，`browser_get_text.offset` 可继续读取长页面。

隐藏标签的原生按键操作会临时将输入控件放到不可见宿主下启用，操作结束后恢复。这样可发送可信按键并保留浏览器默认编辑行为，同时保持用户当前标签不变；焦点模拟的启停按序等待，不重放失败的输入。

普通配置的平台 Cookie 每 5 秒检测一次，只向界面提供存在布尔值，不保证账号会话仍有效。无痕配置不进入平台检测或普通后台发现。B站固定历史请求、B站／小红书／抖音／知乎提取器和已有发现调度继续使用。X 的 auth_token／ct0 与 Reddit Cookie 继续仅用于已有本机 CLI 发现链路；Reddit 的应用管理凭据在确认退出登录后撤回，不删除用户独立设置的凭据。网页工具不返回原始 Cookie，读取正文会进入配置的模型上下文。未加载的内容、网站访问限制和验证码仍需要按网站规则处理，登录不代表获得全站全部数据。

## 验证

```powershell
npm run typecheck
node tests/embedded-browser.test.mjs
node tests/browser-bridge.test.mjs
node tests/extension-panels.test.mjs
node tests/workbench-snapshot.test.mjs
cargo check --locked --manifest-path src-tauri/Cargo.toml --lib -j 1
cargo run --locked --manifest-path src-tauri/browser-smoke/Cargo.toml --target-dir src-tauri/target -j 1
cargo test --locked --manifest-path src-tauri/browser-smoke/Cargo.toml --target-dir src-tauri/target -j 1
```

Windows 原生烟雾测试包含生产模块，使用随机临时配置目录和仅监听 loopback 的网页服务，检查真实导航、Cookie／localStorage、前进后退、无痕隔离、书签、缩放、弹窗、查找、网站数据清理与扩展；并发送乱序布局更新。代理链路验证 HttpOnly 登录后的实际页面读取、表单掩码、隔离上下文防页面覆盖、原生输入、会话标签绑定、后台页面共享登录但不抢焦点／写历史、超时与取消清理、过期编号拒绝、平台检测，以及检查器关闭后继续读取和重新接回。不会访问用户浏览器配置或外部网站。临时目录路径打印在控制台供检查。下载／上传、打印原生对话框、真实平台账号、OAuth、媒体及多显示器 DPI 仍需桌面人工验收。
