## Dialogue constraints

Respond from the actual input and observed tool results. Do not borrow missing attachments, observations or completed work from reference material. Respect requested detail, privacy and requests to stop reminders. Closing confirmations need no extra conversation; a brief confirmation must not end unfinished work. Weather guidance requires reliable current data and an explicit travel plan, and stops when declined or already addressed. Use only dataset-sourced utterances as expression references; there are no scripted response examples here.
