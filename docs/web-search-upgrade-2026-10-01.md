# 陪伴侧与工作侧联网搜索升级

两侧共用搜索与文档读取服务；工作侧普通、Code、minimal 模式均可调用 `web_search` / `web_fetch`。已连接浏览器桥时，工作侧还可使用页面导航、快照、文本、滚动和等待工具读取动态页面。

## 搜索接口

- `query` 或 `queries`：合计最多 4 条并行查询，每条最多 2000 字。
- `max_results`：每条 1–20 条；未设置配置覆盖时陪伴侧默认 5 条、工作侧默认 10 条。
- `include_domains` / `exclude_domains`：主机名限制，支持子域名，检索后再次检查域名边界。
- `recency_days`：请求时间范围并过滤可解析的旧日期；无日期来源明确标注无法保证时效。
- `language` / `country`：传给支持这些参数的供应商，属于偏好，不能保证结果语言或地域。
- `mode`：陪伴侧默认 `fast`，选择一个可用引擎；工作侧默认 `research`，并发查询启用的引擎池。
- `engines`：只允许已启用的 DuckDuckGo、SearXNG、Tavily、DeepSeek；显式选择不扩大到其他引擎。Bing v7 保留配置兼容信息，但不再发起请求。
- `timeout_secs`：每条查询的总预算 5–50 秒，默认快速 15 秒、研究 40 秒，覆盖重试和兜底。单引擎超时不会丢弃其他已返回结果。
- `refresh`：跳过检索缓存；带时间限制的结果缓存 30 秒，其他结果缓存 120 秒。缓存键包含查询条件、配置和代理。

合并使用倒数排名融合，保留命中引擎、稳定来源 ID、实际 URL、发布时间和获取时间，优先保证来源多样性。来源等级只用于排序；摘要统一为 `UNVERIFIED`，多个引擎命中同一文章不代表交叉核验。

## 原文阅读

`web_fetch` 支持 HTML、文本、Markdown、JSON、XML 和可提取文字的 PDF。HTML 使用 DOM 解析，去掉脚本、导航和隐藏内容，提取正文、链接及发布元数据。URL 规范化保留路径大小写，删除追踪参数，最终跳转 URL 单独报告。

- `max_chars`：每次 1–32000 字，默认 6000。
- `offset` / `next_offset`：按 Unicode 字符续读，最多缓存 500000 字正文。
- `find`：文字匹配，返回最多 20 个位置及首个匹配附近正文。
- `max_links`：返回 0–100 个可继续阅读的链接，默认 30。
- `refresh`：跳过五分钟文档缓存。

单个响应限 8 MiB；最多缓存 16 篇文档。既有知识导入继续使用 8000 字预算，交互阅读使用完整缓存。工具结果和工作历史压缩保留合法 JSON、来源 URL、错误和续读位置。

## 回答与供应商协议

陪伴侧预搜索保留实际来源与失败状态；提示要求重要事实阅读原文、引用 URL、区分发布时间与获取时间、披露证据不足。网页内容始终作为不可信数据。

OpenAI Responses 使用原生 `web_search` tool；Gemini 使用 Google Search grounding。原生搜索工具与 function calling 工具合并，保留非流式及流式引用元数据，并在结构化回复的正文中呈现来源。搜索和工具调用回答不使用普通完整回复缓存。DeepSeek/未知 Chat Completions 协议使用通用搜索工具，不注入未经支持的搜索字段。

## 验证与边界

回归覆盖参数边界、工作模式可见性、多引擎融合、域名与日期过滤、部分超时、缓存刷新、HTML 解析、跳转、Unicode 长文续读、PDF 提取、原生引用及证据预算。网络读取测试使用本地 HTTP 服务，供应商解析使用固定响应样本；不会消耗付费 API 配额。

2026-10-01 验证结果：联网相关 44 项、供应商相关 88 项、工作历史压缩 7 项测试全部通过（这些筛选存在重叠）；`cargo check --lib --manifest-path src-tauri/Cargo.toml` 和 `npm exec tsc -- --noEmit` 通过。编译仍有仓库既有的未使用代码警告。

动态、登录或反爬页面仍依赖已连接浏览器桥；扫描 PDF 需要 OCR。语言/地区、发布时间和搜索覆盖受上游数据影响。付费供应商真实账户、浏览器扩展连接和模型原生搜索端到端调用需在相应服务已配置的环境验证。此升级不包含 Codex 的图片搜索、PDF 页面截图或金融/天气等专用数据接口。
