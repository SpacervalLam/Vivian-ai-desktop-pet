# 心情与回复的双向联动

本轮使用现有心理系统与现有回复后反思调用，不新增一套独立心情数值，也不增加嵌入或 LLM 请求。界面的 `get_current_mood` 已经来自 `PsychologyManager.compute_mood()`；现在回复表达也读取该统一快照。

## 数据流

1. 提示词最终组装时读取统一心情，将快照写入请求内的 `metadata.mood_before_reply`。精力、压力、专注度作为内部表达参考：精力低减少铺垫和支线，压力高减少调侃，专注低分点清晰表达。保留连续情绪语气偏置；用户实际需要、必要答案、事实与能力优先，不要求表演疲惫或报出数值。
2. 主模型照常生成回复。现有反思调用同时看到回复前快照、当前用户输入、实际回复与近期对话，输出七维 `emotion_update`，语义明确为本轮结束后的净变化。
3. 心理系统应用净变化，保存到现有 psychology.json；下一轮提示词和界面投影使用更新后的状态。压力和专注度会随底层情绪变化；精力仍由需求与空闲时间派生，不随某个情绪标签直接加减。

回复内容参与反馈的例子：真实地表达并梳理不满，可以轻微降低 anger；有内容的新想法可以增加 curiosity；本轮互动确有宽慰可以降低 fear/sadness。不能仅因为说了一句安慰，就认定问题已解决或用户接受了；礼貌感谢、引用、虚构和沿用旧语气不算新的自身经历。`ai_emotion` 仍用于回复表面情绪评分，不直接用标签增大内部状态。

## 修复与限制

- 修复反思提示词字段示例：appraisal 使用实际六维 threat/rejection/control/fairness/novelty/significance，emotion_update 补齐 closeness，behavior_drive 使用实际八维。
- 原先 appraisal 映射情绪后，又叠加直接 emotion_update，可能对同一事件计数两次。现在直接增量优先；缺失才使用 appraisal 映射。appraisal 仍参与事件记录和需求更新。显式七维全零表示情绪不变化，阻止备用情绪映射。
- 输入建议每维 ±0.08；应用人格敏感度后，限制每维 ±0.12、整轮七维绝对变化总量 0.24。LLM 已给出净变化时直接应用，不再次经过情绪间作用，避免把明确的情绪缓解重新放大；appraisal 备用映射包含通道间作用，也受相同预算约束。状态仍限制到 [0,1]。这些是工程限幅，尚未通过真实对话校准。
- 全零或全为非有限值的反馈不再触发情绪间作用，避免普通回复不断放大既有情绪。自然稳态调节与需求／关系更新仍独立运行，所以整个心情快照并非一定不变。
- 预算在共享 `apply_llm_output` 更新入口生效，其他使用此入口的主动行为、世界事件或情感桥接反馈也会更平缓。直接用户动作及其他专用心理更新入口保持其原有规则。
- 反思失败、超时或没有变化证据时不新增标签驱动的反馈。沿用现有降级和超时机制；本轮没有降低反思调用延迟，也没有加入额外语义分类请求。

## 验证范围

新增回归覆盖：回复前快照与实际文本进入反思；反思可解析负向增量与 closeness；直接反馈覆盖 appraisal、显式零阻止备用映射；敏感度和通道作用后的总预算；非有限值；100 次零反馈不自我放大；回复反馈更新压力／专注度并正确持久化；中英日表达控制保留必要回答。

这些测试验证数据流与数值约束，不证明 LLM 产生的心理解释一定合理。真实配置下仍需观察普通任务、安慰、分歧和持续聊天，确认变化来源、幅度和语气是否贴合；未调用用户配置的远程模型。

最终验证：新增 8 项回归通过；`cargo test --lib --offline` 的反馈测试筛选通过，测试库完整编译通过；`cargo check --lib --offline` 与 `git diff --check` 通过。持久化测试等待实际后台快照写入后重载，并使用浮点容差验证数值。

扩展验证覆盖心理系统、提示词、反思、生成、情感桥接及并行路由，共 148 项通过、11 项失败、1 项基准默认忽略。因此不能把相关模块报告为全通过；失败范围如下：

- 心理模块最后一轮有 3 项旧断言失败：`emotion::tests::test_valence`、`homeostasis::tests::test_offline_closeness_preserved`、`pet_state::tests::test_compute_pet_state_angry`。这些公式与断言本轮未改动。
- `manager::cold_shoulder_tests::test_user_answered_relief_cures_cold_shoulder` 首轮失败、后续通过；夹具复用固定临时文件路径，会读入先前运行状态，尚未改为隔离夹具。
- 情感桥接 8 项旧测试失败，包括仍期待已经移除的无模型关键词路径（期望 `keyword`/happy，运行时实际 `no_llm`/neutral）、表情触发，以及期待单次低强度增量就成为主导情绪的夹具。桥接代码与这些断言本轮未修改，未为通过测试恢复关键词分类。

新增反馈与提示词联动测试全部通过；上面的旧断言与夹具问题保留并单独记录，不改动对应运行时公式来迎合测试。
