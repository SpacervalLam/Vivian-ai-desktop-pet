# Vivian

**具备记忆、情绪与主动性的 AI 桌面宠物**

Rust · Tauri 2 · React 18 · Q 版 Sprite 动画

</div>

Vivian 是面向 Windows 的多角色桌面陪伴应用。Vivian 与 Nana 可以同时在线，各自拥有独立的记忆、人格、心理状态和对话历史，也能彼此交谈。除日常陪伴外，它还提供工作智能体、语音、联网检索、桌面工具及可选的 3D 公寓。

角色数据保存在本地；模型、远程嵌入、搜索、天气和语音等服务按配置访问外部端点。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 多角色陪伴 | 流式私聊、群聊、跨角色对话、主动开口；支持中文、英文和日文界面。 |
| 记忆与成长 | 跨会话记忆、用户画像、关系、日记与笔记；相处方式可从真实用户记忆中逐步调整，保留来源并支持撤回。 |
| 情绪与感知 | 时间、天气、媒体、前台应用与活动观察参与回复；心情影响表达，并在对话后更新。 |
| 桌面互动 | 拖动、轻触反馈、长按互动、动作与表情、鼠标跟随；角色贴纸可用于聊天窗口及桌面方形气泡。 |
| 工具协作 | 文件、应用、媒体、截图识别、待办、提醒、搜索和网页读取；按权限执行，由角色根据实际结果回复。 |
| 工作智能体 | 代码阅读与修改、命令执行、工作区、终端、计划、子任务和成果回流；工作模型独立配置；工作页支持会话全文搜索与键盘快速切换。 |
| 扩展能力 | 插件声明可执行能力或配置数据，技能仅提供按需加载的使用指导；支持自建工具、MCP 与真实浏览器标签页桥接。 |
| 语音与远程 | 语音识别、TTS、实时语音及手机端 Web 访问；按所选服务配置。 |
| 3D 公寓 | 独立可选插件，包含房间与街区场景；基础程序可单独安装和运行。 |

陪伴侧由主智能体保留角色与记忆、决定工具调用；多步执行使用隔离的中性上下文，工具回执交回角色表达。前台查询、截图等直接等待实际结果。前台窗口与最近外部窗口有明确区分，运行中的录屏软件不等于已经确认正在录制；截图识别还取决于所配置的视觉模型是否可用。

联网检索可配置 Exa、Perplexity 及 OpenAI/Grok/Claude 原生搜索，统一展示来源；网页与 PDF 原文按会话保存，支持来源 ID 续读、页内查找及按问题提取。新增后端默认关闭，需在网络搜索设置中配置凭据；模型原生搜索会产生对应模型与搜索 API 费用。

工作页点击搜索图标或按 `Ctrl+K` 可搜索会话标题、消息内容和工作区；用方向键选择、`Enter` 打开，`Alt+1–9` 快速打开前九项，`Esc` 关闭。记忆页的匹配内容会高亮显示。

工作智能体的项目经验保存在工作区 `.vivian/memory.md`。用户的常驻约定、关键约定和权限边界分节由程序保护并完整注入，详细经验则先展示最多 2,000 字符的主题导航，再按需要搜索、分页读取；文件修改后下一轮生效。`/memory` 查看完整原文，`/memory <内容>` 写入常驻约定，`/memory 提炼` 按完整文字材料分批沉淀经验，包含文字文件引用，排除重复的图片与组件二进制数据。

新条目附稳定 ID，可读取 `.vivian/memory_entries/` 中的逐条正文、来源会话、原材料路径、消息索引及观测时间；脱敏原材料存放在 `.vivian/memory_sources/`。消息索引从零开始，相对于来源 JSON 的 `messages` 数组。模型选择的来源索引会由程序校验范围，但不等同于事实验证；默认状态为未验证，验证时间为空。明确纠正会关联被替代的条目，并在原文标记旧结论失效，保留历史来源。旧记忆没有来源时不补造。

同一应用进程中的项目记忆提交按文件串行处理，并采用原子替换；LLM 整理完成后比较原始文件内容，文件已变化时拒绝旧结果。来源材料保存会话观测时间（Unix 毫秒）和验证状态；自动整理默认标记未验证，验证时间为空。工作会话也在取得提交锁后采集快照，避免并发保存时旧快照覆盖新快照。

后台记忆任务的稳定 ID 与经验正文一起原子提交，重启重放不会重复追加。同项目按队列顺序处理，不同项目最多并发两个任务；失败次数、下次重试时间与脱敏原因保存到磁盘，连续失败八次后暂停。`/memory 状态` 查看当前项目队列，`/memory 重试` 恢复处理。

工作会话独立存储在用户数据目录的 `coding_sessions/`，通过原子索引恢复；首次加载兼容迁移旧 `coding_sessions.json`。保存数量不再限制为 30 个，界面先显示最近 30 个，再通过“加载更多历史会话”分页查看；直接打开旧会话和恢复上次会话不受当前分页限制。后端启动只读取最近 30 个会话的完整历史，其余仅保留轻量索引；分页不读取旧消息，打开或操作旧会话时按需恢复完整历史。保存仅写入已加载会话，未加载历史继续保留。首次旧索引升级或损坏恢复会扫描一次历史文件。

记忆页提供长期记忆、共同经历、对话记录和用户画像。原始聊天按实际交流归组，广播、换话题和运行会话切换不拆分；会话卡片内独立切换原文与摘要，长会话分段整理并支持中断后继续。共同经历展示具体事件的跨会话时间线，串联计划、进展和结果，每条进展可追溯用户原话，不重复展示聊天摘要。事实、偏好和约定从原话独立提取，内心活动留在心智系统；仅原始对白的括号动作以灰色斜体展示。用户资料自动更新画像，手工锁定字段保留。

心智、记忆、日记 / 笔记 / 计划这几页都是整页纸面：左右留白按窗口宽度伸缩，且**两侧等宽**（外壳原先只给了左边的呼吸位，右侧已补齐对称的一份）。记忆页额外把自己的纵向滚动条隐藏，滚动照旧（滚轮 / 触控板 / 键盘），页宽因此恒定、内容增减不再横向跳动；其余页面的滚动条不受影响。工作页是密集工作台，保持它自己的内边距不变。

提醒分别记录原定时间、重试时间与已确认投递次数；失败重试不计入投递次数，提醒措辞随成功投递变化，不推断用户是否已读。

桌面工具支持一次操作后截屏观察，操作回执区分输入已完成与目标已验证；观察失败不会自动重放输入。调度任务在执行前保存状态，重启后恢复提醒，对执行结果未知的工具任务显示恢复错误，避免重复副作用。

发送消息后，桌宠会播放「思考中」循环，收到首个可见回复文字后转入说话动作；取消、失败或没有回复时结束等待。

## 快速开始

### 使用安装包

从 [Releases](https://github.com/SpacervalLam/Vivian-ai-desktop-pet/releases) 获取对应发行包。基础安装程序使用 NSIS；如需 3D 公寓，将配套公寓 ZIP 与 setup 放在同一目录，并在安装时勾选。安装后可在「设置 → 通用」启用或禁用公寓。

首次运行，在设置中配置模型端点、模型名和 API Key，使用一键检测检查连接。再按需要配置工作模型、语音、搜索和外部连接。当前支持 Windows 10 / 11，需要 WebView2。

### 从源码运行

准备 Rust **1.88 或以上**、Node.js **22 或以上**、Windows MSVC C++ 构建工具与 WebView2。角色图集随仓库分发，开发模式无需另行准备角色模型。

```powershell
git clone https://github.com/SpacervalLam/Vivian-ai-desktop-pet.git
cd Vivian-ai-desktop-pet
npm install
npm run tauri:dev
```

`npm run dev` 只启动前端 Vite 服务；完整桌面功能应使用 `tauri:dev`。

### 构建与检查

以下命令均在仓库根目录运行：

```powershell
# 类型检查、Node 测试和可移植运行契约
npm run check

# 主程序 Rust 单元测试（独立临时数据目录）
npm run test:rust

# 记忆与提示词离线契约评估
npm run eval:companion

# 主前端：类型检查、构建及公寓外置边界检查
npm run build

# Rust 编译检查
cargo check --manifest-path src-tauri/Cargo.toml

# 基础程序 NSIS 安装包
npm run tauri:build

# 独立构建公寓插件 ZIP
npm run build:apartment

# 生成基础 setup、配套公寓 ZIP 和校验信息
npm run package:small
```

基础安装包位于 `src-tauri/target/release/bundle/nsis/`，配套发行文件位于 `release/`。主程序的 `npm run build` 不构建公寓，Three.js 和场景资源由插件独立管理；安装与预览方式见 [公寓插件说明](plugins/3d-apartment/README.md)。

CI 在 Windows 验证主程序 Rust，在 Windows/Linux/macOS 验证前端与可移植契约；原生桌面输入目前仅支持 Windows。离线评估不调用模型，不代表对话质量测试。原生沙箱与角色动画检查使用独立入口，命令及验收范围见 [代码 Wiki](CODE_WIKI.md)。

发布版使用加密美术资源包。打包前须准备匹配的 `src-tauri/vivian.bundle.enc`、`vivian.bundle.index.json` 与 `asset_key.bin`；密钥不进入版本管理。资源更新后也需重新生成匹配的包、索引与密钥，不能把缺少密钥时可编译的开发兜底当作可用发行包。

## 配置与数据

- **模型与用量**：为对话、内部工具执行、推理、记忆和视觉等任务独立分配模型；可控制是否发送温度与最大输出 Token，以及通过适配描述配置思考模式、强度和请求字段。“API 请求配置”支持完整请求体合并覆盖、模板式完全替换、完整请求体示例与草稿预览；完整覆盖最终生效，旧版参数覆盖仍保留发送开关优先级。一键检测展示各路由结果和错误原因，用量页按任务统计调用。
- **模型连接与回退**：统一处理端点路径、HTTP 错误、有限重试和流式超时；结构化输出仅在明确不支持时降级。流式回复在首个有效输出前可回退，开始输出后不自动重放，避免重复文字或工具调用。
- **搜索与网页**：支持 DuckDuckGo、SearXNG、Tavily 和 DeepSeek 搜索后端，按启用状态使用。搜索默认陪伴侧 5 条、工作侧 10 条；可配置结果数、引擎和过滤条件，网页正文支持分页续读。旧 Bing 配置只保留兼容提示。
- **工具权限**：风险等级、访问级别、工作区与确认策略共同约束调用；执行上下文不会因工具返回内容获得额外授权。浏览器桥和 MCP 在外部连接页管理。
- **语音输入（ASR）**：「设置 → 语音输入」选择应用共用的识别引擎、语言和服务连接。Whisper 支持录音结束后识别、SSE 逐步显示文字，以及兼容 Realtime 的边录边识别；Realtime 模式需要相应服务支持，本地 HTTP 启动不保证兼容。
- **语音输出（TTS）**：「设置 → 语音输出」先选择角色，再配置引擎和音色。GPT-SoVITS 的 GPT / SoVITS 模型可直接输入、从本机扫描建议中选择或浏览文件；远程 / Docker 部署填写服务端路径，无需本地安装目录。多角色共享服务时为每个角色配置两套权重，模型切换与合成串行执行；独立服务或本地双实例可并行合成。修改模型、参考音频和语言等配置后使用对应的新缓存；相同路径的模型文件被原地替换后需清空缓存。
- **本地数据**：默认位于 `%APPDATA%\vivian\`，配置为 `config.yaml`，角色数据按 `characters/<角色 ID>/` 分隔。
- **贴纸**：「设置 → LLM → 聊天表情包」调整两位角色的频率，或导入、替换 PNG；内置各 12 张压缩 WebP；用户替换的旧消息保留原资源版本。
- **备份与恢复**：「设置 → 备份与恢复」可导出 `.altn`、导入备份或恢复初始状态；备份前刷新对话和记忆，导入和重置需要确认并重启。

恢复初始状态会清除记忆、历史、心理与成长记录、笔记、工作会话、截图，以及用户数据目录中的自建技能、插件和 MCP 配置；保留主配置、凭据、安全白名单及必要运行设施。重启时先完成清扫再初始化，删除失败时保留重置标记并阻止读取旧数据。需要保留使用期数据时，先导出备份。

陪伴侧对话历史使用可重建的 JSONL 偏移索引：启动、近期消息与分页仅解析所选正文，首次建立索引或历史文件被改写时扫描一次。原始历史始终保留；完整会话投影、导出等全量操作仍按需读取全部记录。

陪伴长期记忆提取按角色使用持久化 FIFO 队列，每轮保存带消息 ID、角色、渠道和时间的来源。满 3 轮提交；不足 3 轮在闲置 60 秒后提交。失败按指数退避重试，分析结果与逐操作回执落盘，删除操作固定原目标 ID。重启恢复队列及尚未落盘的原始消息；清空记忆会同时暂停和清空队列。摘要整理按角色串行，提交时校验源记录和已读取的文件版本，先原子落盘再缩减上下文；版本冲突时重新加载存档，保留整理期间新增的消息。

陪伴记忆检索共享 1.8 秒等待预算，各召回路径与验证器有独立上限；超时保留已完成过滤的结果。运行元数据 `memory_retrieval_timing` 记录阶段耗时、超时和跳过原因，预算只约束异步等待，不代表完整回复的耗时上限。
